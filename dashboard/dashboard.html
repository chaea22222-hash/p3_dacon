전체 흐름
r3 핵심 수식
# 피험자 사전 확률 (anchor) subject_mean = mean(labels | same subject_id) # 시간적 지수 감쇠 가중 평균 weight = exp( -|train_date - pred_date| / decay ) local_avg = Σ(weight × label) / Σ(weight) # 최종 블렌딩 prediction = α × subject_mean + (1 - α) × local_avg prediction = clip(prediction, 1e-6, 1-1e-6)

⚠️ OOF 검증 시 exclude_self=True로 해당 행을 local_avg 계산에서 제외하지만, subject_mean에는 자기 레이블이 포함되어 OOF는 낙관적 추정입니다.
