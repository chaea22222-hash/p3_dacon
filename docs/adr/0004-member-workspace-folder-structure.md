# 팀원별 워크스페이스 폴더 구조 도입

`src/팀원id/전처리/`, `src/팀원id/모델이름/` 구조를 채택한다. 기존 레거시 스크립트(`train_r3.py` 등)는 `src/` 루트에 그대로 유지한다.

MLops 파이프라인 구축 후 다음 목표는 예측 성능 향상이며, 각 팀원이 독립적으로 전처리와 모델을 실험해야 한다. 단일 `src/` 평면 구조는 파일명 충돌과 코드 소유권 모호함을 유발한다. `src/model/팀원id/` 처럼 중간 계층을 두는 안도 검토했으나, `src/팀원id/`가 경로가 짧고 `sys.path.insert(0, parents[2])`로 일관성 있게 공유 유틸을 참조할 수 있어 선택했다. 레거시 스크립트 이동은 대회 기간 중 불필요한 리스크이므로 동결한다.
